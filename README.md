# Module

Docker container to run [bonefish](https://github.com/DylanCosto/bonefish). Dockefile is adapted from https://github.com/DylanCosto/bonefish/blob/v0.5.0/Dockerfile

To add as a submodule:
```
git submodule add -b bonefish https://github.com/chusj-pigu/wf-modules modules/local/bonefish
```
